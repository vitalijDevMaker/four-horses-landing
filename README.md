# Четыре лошади — адаптивный лендинг (тестовое задание)

👉 **[Открыть готовую страницу →](https://vitalijdevmaker.github.io/four-horses-landing/)** 👈

## Технологии

- HTML5, CSS3 (Flex, Grid, медиазапросы, keyframe-анимации)
- JavaScript ES6 (чистый JS, без библиотек и фреймворков)
- Сборка: **Vite**
- Деплой: **GitHub Pages**

## Реализованные требования

- Придерживайтесь принципа Pixel Perfect.
- Страница должна быть адаптивной, хорошо выглядеть при любом размере экрана (нет горизонтального скролла, нет уезжающих за экран текстовых элементов, текст не наезжает на другой текст или изображение).
- Избегайте дублирования текстового контента в мобильной и десктопной версиях.
- Добавьте корректно работающую бегущую строку.
- Кнопки на стартовом экране являются якорями и ведут к соответствующим блокам.
- Карусель с карточками участников должна быть зацикленной и меняться автоматически через каждые 4 секунды.
- Карусель с этапами не должна быть зацикленной и не должна автоматически менять слайды.
- Добавьте анимацию по своему усмотрению.

## Быстрый старт (разработка и деплой)

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/vitalijdevmaker/four-horses-landing.git
cd four-horses-landing

# 2. Установите зависимости
npm install

# 3. Запустите дев-сервер (Vite)
npm run dev

# 4. Сборка продакшн-версии
npm run build

# 5. Деплой на GitHub Pages
npm run deploy

# (опционально) Оптимизация изображений
npm run images:optimize
```
